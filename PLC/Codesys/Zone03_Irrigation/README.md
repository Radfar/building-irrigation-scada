# CODESYS — Zone 03 Irrigation

This folder contains readable CODESYS source references for engineering review. The native CODESYS project file is intentionally not stored in this repository.

## Available source references

- `FB_IrrigationZone VAR list` — function-block interface/declaration listing.
- `FB_IrrigationZone.reference.st` — Structured Text implementation reference.
- `GVL_SCADA` — global SCADA variable declarations.
- `PLC_PRG` — program-level function-block wiring and command consumption.

These files are reference material, not a complete importable CODESYS project. Their exact equivalence to the current native application has not been independently verified in this repository review. Preserve the source content when updating them, and record CODESYS version, capture date and source revision when known.
