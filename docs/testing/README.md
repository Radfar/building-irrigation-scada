# Functional testing

This directory contains repeatable test procedures and recorded results for the Industrial Water Management testbed.

## Test records

- [Zone 02 — moisture-based automatic control validation](zone02-moisture-control-validation.md)

Test documentation describes the test configuration, input conditions, expected behavior, observed results and limitations. Visual evidence is maintained separately under `media/testing/`.

## Evidence conventions

- Record the controller/runtime, operating mode and relevant communication path.
- Distinguish generated test inputs from measurements supplied by physical field sensors.
- Record the actual controller response and the corresponding HMI indication.
- Do not claim physical commissioning based on simulator-only testing.
