# Zone 02 — moisture-based automatic control validation

## Objective

Document the functional test of Zone 02 moisture-based irrigation control using the Rockwell Micro850 controller, Node-RED as a controlled test-input source, and the Web SCADA application as the supervisory monitoring interface.

## Test configuration

| Item | Configuration |
|---|---|
| Zone | Zone 02 |
| Controller | Rockwell Micro850 |
| Controller environment | Connected Micro850 simulator |
| Test-input tool | Node-RED |
| Operating mode | AUTO |
| Supervisory interface | Building Irrigation Web SCADA |
| Communication integration | EtherNet/IP between the SCADA backend and Micro850 |

## Test procedure and scenarios

The controller was placed in AUTO mode before applying the test inputs.

### Scenario 1 — low soil moisture

Node-RED injected a soil-moisture value below 30%. The Micro850 processed the input using its configured automatic control logic. The irrigation response was observed through the controller simulator and the Web SCADA application.

### Scenario 2 — high soil moisture

Node-RED then injected a soil-moisture value above 70%. The Micro850 processed the new condition and performed the configured high-moisture response.

## Verification and observed result

Both scenarios completed successfully in the test environment. The following process information and equipment states were visible in both the Micro850 simulator and the Web SCADA application:

- Soil-moisture value
- Pump feedback
- Irrigation valve state
- Automatic control response

The observed values and equipment indications were consistent across the controller simulator and the supervisory HMI during the demonstration.

## Result

**Pass — both moisture test scenarios produced the expected configured automatic-control behavior.**

This validates the integrated simulated test path from Node-RED test-input generation, through the Micro850 control logic, to the Web SCADA monitoring interface.

## Scope and limitations

- Moisture values were generated by Node-RED for controlled functional testing; this test does not validate a physical soil-moisture sensor or its calibration.
- The controller was tested in its simulator environment; this is not evidence of physical field commissioning.
- The test validates the configured control behavior and the visibility of process values in the Web SCADA application. It does not establish safety certification or production readiness.
- This document does not change PLC logic, protocol drivers, backend services or HMI control logic.
