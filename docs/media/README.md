# Project media

This directory stores visual evidence and demonstration media associated with the Industrial Water Management testbed.

## Organization

- `screenshots/` — HMI screenshots, including dark and light themes.
- `testing/` — screenshots, flow captures and edited videos associated with functional tests.

Use descriptive filenames and reference media from the relevant documentation. Avoid committing credentials, private network information or unredacted sensitive data.

For large video files, prefer a GitHub Release or an external video host and place the link in the relevant media README.
